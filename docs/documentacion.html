Documentación

wi-mod 0.20.0 es una biblioteca local y portable de mods. Junta fichas de varios juegos y webs en tu PC. Puede enlazar los archivos del mod en la carpeta Data del juego.

Qué guarda

  • Ficha del mod: enlace, portada, resumen, categoría, juego y plataforma.
  • Juego activo, categorías y modpacks para ordenar la biblioteca.
  • Usuario y clave locales. No hay cuenta en la nube ni telemetría.

Descargar y abrir

  1. Windows: el portable wi-mod-portable.zip o el instalador de Releases (wi-mod_*_x64-setup.exe).
  2. Descomprime el zip donde quieras y ejecuta wi-mod.exe. No hace falta instalador.
  3. La primera vez creas tú el usuario. Esa sesión solo existe en este PC.
  4. Linux está en beta (AppImage / deb / rpm en el mismo release, cuando el build de esa versión terminó).

La demo web enseña la interfaz en el navegador. La biblioteca de verdad es la del escritorio: la demo no reemplaza la carpeta data/ de tu PC.

Dónde están tus datos

Todo queda junto al programa, en la carpeta data/. La base es SQLite (wi-mod.sqlite). Puedes mover o borrar la carpeta entera; el programa no deja restos de un instalador.

No subas data/ a git. Ahí están usuarios, mods y claves.

Añadir mods

Pega la URL de la ficha oficial o busca desde la app si tienes clave. wi-mod reconoce la plataforma por el dominio:

PlataformaClaveQué hace
Nexus ModsSíBuscar y guardar fichas. Variable WI_MOD_NEXUS_KEY o WI_MOD_API_KEY.
ModrinthNoAPI pública. Búsqueda de mods, modpacks y resource packs.
CurseForgeSíWI_MOD_CURSEFORGE_KEY.
Steam WorkshopSíWI_MOD_STEAM_KEY.
ModDBNoGuardas la ficha desde la URL de moddb.com. También hay tema visual ModDB.
RAWGSíNo es una web de mods. Sirve para buscar el juego y ficharlo. WI_MOD_RAWG_KEY.
IndependienteNoCualquier otro enlace que quieras archivar a mano.

Las claves se pegan en Ajustes. En el escritorio también puedes dejarlas en data/keys.json (plantilla: data/keys.example.json). Si ya hay una clave guardada, el arranque no la pisa.

Temas e idioma

El selector de paleta cambia colores de la interfaz: Nexus, Modrinth, CurseForge, Steam, ModDB y RAWG. No cambia de dónde salen los mods.

El idioma de la interfaz es español o inglés (ES / EN). La elección se guarda en este equipo.

Desarrollo

Hoy conviven el escritorio Python (pywebview) y el escritorio Tauri v2. La UI compartida está en web/.

pip install -r requirements.txt
python app.py

npm install
npm run tauri:dev

Tauri necesita Rust y el WebView del sistema. El release de GitHub se publica cuando cambia el número de versión en wi_mod/__init__.py y package.json a la vez.

Los mods siguen siendo de sus autores y de la web donde los publicaron. wi-mod solo guarda tu índice local.
